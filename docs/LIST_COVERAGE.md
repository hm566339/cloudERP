(`src/hooks/useListQuery.js`) handles two-way URL search parameter state synchronization, out-of-bounds page clamping, automatic reset to page 1 on filter or search mutation, and Stale-While-Revalidate caching.\n2. **Debounced Text Input**: Built-in 350ms debounce eliminates refetch storms during typing across all search bars.\n3. **Abortable Signal Support**: `useListQuery` and `useApiQuery` manage internal `AbortController` instances that cancel in-flight HTTP requests when components unmount or when queries are superseded by subsequent user input.\n4. **SearchInput & Pagination**: Standard components ensure consistent accessibility, keyboard navigation (`Esc` to clear search, `⌘K` focus), rows-per-page selectors, and accessible pagination buttons.\n
